# sita-ram-invite

Royal Vedic Wedding Invitation for Anirudh & Vaidehi.

## Commands

```bash
# Start local development server
npm run dev

# Build standalone production bundle
npm run build

# Preview build locally
npm run preview

# Live Edit initialization (from project root)
npm run live-edit
# or:
node ../live-edit/skills/live-edit/scripts/live.mjs init
```
